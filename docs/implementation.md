## 数据与模型

馆藏数据来自[克利夫兰艺术博物馆公开 API](https://openaccess-api.clevelandart.org/)，逐件筛选 CC0 图像与元数据，唐、宋、元、明、清各4件。导入脚本保存原始名称、文化、工艺、说明、尺寸与馆藏链接，中文资料从馆方字段翻译。

历史器物展示采用馆藏照片的前景分割轮廓建模，已为20件馆藏生成嵌入正面照片纹饰的GLB。官方扫描模型尚未全部导入；已有Sketchfab模型链接保存在对应记录中。馆藏实际尺寸与高度为30的展示坐标分开保存。

上传重建采用[官方 TripoSR 源码与权重](https://github.com/VAST-AI-Research/TripoSR)，浏览版本最多18,000面，完整网格保留用于下载和测量。可观测性热力图根据表面法线与假设相机方向计算。

云端配置：Gemini 3.8 Flash 负责视觉识别；Atria-Dawn-Preview 负责知识生成、对比解释和自由解释题评阅。密钥保存在被 Git 忽略的后端环境文件中。

## 纹饰修复

原来的馆藏展示只有轮廓和素色材质，默认部位高亮又覆盖了器身颜色。现在将原照片中可见的花纹映射至三维表面，保持上下、左右方向；部位高亮改为边界细线。20件馆藏和已有上传模型均已更新。

纹理已嵌入GLB，正面显示照片纹饰，背面采用正面镜像纹理，前后对称并保持侧面衔接。照片已经包含光照，模型采用[KHR_materials_unlit](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_unlit/README.md)保留照片色彩。投影方向、前后镜像、UV接缝、GLB贴图与材质验证通过，后端共20项测试通过。

启动、配置和验证命令见项目根目录 README。
