### 第二件事：多模态 —— 暂缓（2026-11-25 决定，先不做）

**为什么砍。** 查了一圈，能满足"一张图 + 一段文字进同一个请求"的只有 Hyper3D Rodin，但它的 API 被绑在 Business 版（$120/月），学生项目不用考虑。腾讯云混元生3D 和 Tripo 的图生 3D 都写死"图片和文字互斥"，唯一能同时传的是混元的 Sketch（草图/线稿 + 文字）。也就是说，我们自己能做的只有"文字→图→三维"的级联，本质上还是两段，不是联合条件。

花一天多搭一条本来就要在答辩里解释"为什么不算真联合"的链路，不如先把测试和识图/问答 API 做扎实。

**已核实的选型结论（留着备查，别重复调研）**

| 服务 | 图 + 文字同请求 | 价格 | 结论 |
|---|---|---|---|
| Hyper3D Rodin Gen-2.5 | 支持（1–5 张图 + 可选 prompt） | API 需 Business 版，$120/月 | 排除 |
| 腾讯云 混元生3D | 普通图生不收文字；只有 `GenerateType=Sketch`（草图/线稿）能图和字一起传 | 首开送 100 积分；极速版 15 积分/次、Sketch 25 积分/次 | 暂缓 |
| Tripo API | 不支持，text / image / multiview 三通道互斥 | 图生 ¥1.4–2.1/次，最低充 ¥70 | 暂缓 |

还有一条常被提到的：Hunyuan3D-Omni（腾讯 2025-09 开源，3.3B）能接受"图像 + 点云/体素/包围盒/骨骼"，但**不收文字**，官方写明要 10GB 显存，我们 8GB 卡跑不动。

**已经准备好的东西（别删）**

`backend/test_hunyuan3d_api.py` 留着：混元生3D 的冒烟脚本，图/文/草图三种模式，签名自己算、不装 SDK。以后要捡回来，把腾讯云 SecretId / SecretKey 填进 `backend/.env` 就能跑。

**答辩口径**

只讲"图 → 三维"。被问多模态就答：公开可用模型里没有 8GB 能跑的图文联合，商业 API 里支持联合的只有 Rodin、成本不适合课程项目，所以先把单图链路做扎实，文字入口作为后续工作。这比硬套一个两段式再被追问要好。

## 八、技术备注（改代码前必读）

1. **两个 key 现在都是空的。** `backend/.env` 里 `ATRIA_API_KEY`、`GEMINI_API_KEY` 的值长度都是 0，所以 `/health` 返回 `textConfigured:false`、`visionConfigured:false`，识图走降级、AI 讲解走本地检索，`live_smoke.py` 第一步就会报"模型服务尚未配置密钥"。这不是代码 bug，是没填 key。填完重启 8000 即可，`providers.py` 会自动读 `.env`。验证命令：`python -c "from app.providers import provider_status; print(provider_status())"`，两个 `*Configured` 都变 True 才算通。
2. **跑 `live_smoke.py` 之前先停掉 8000 上的 uvicorn**，或在命令前加 `QJQN_PRELOAD_MODELS=0`，否则两个进程同时往 8GB 卡里塞模型，容易 OOM。
3. **8GB 显存同一时刻只让一个引擎驻留。** 切换引擎会主动释放另一个（`_release_others`），别删这段逻辑，否则 Hunyuan 会从 1 分钟退化到十几分钟。
4. **后端 python 用完整路径** `D:\SoftWare\Anaconda\envs\qjqn-gpu\python.exe`，`conda activate` 无效。
5. **水密有两个口径。** 数据库里 GLB 按索引算的 `is_watertight` 是 False，那是 UV 接缝复制顶点的正常现象；按 3D 位置合并后欧拉数 = 2 才是真的几何水密。答辩说"几何水密"，不说"模型水密"。
6. **`/health` 里的 available 是"真能跑"**，不是"文件存在"。sf3d 要 `QJQN_ENABLE_SF3D=1` 才启用，instantmesh 要有 HF token 才算可用。
7. **Meshroom 不认中文路径。** 项目根在 `D:\软创赛`，所以多图管线强制在英文临时目录跑，完成后再用 Python 写回 outputs。这段别简化。
8. **单图和多图共用一张任务表**，同一个人同一时刻只能有一个任务在跑，第二个会返回 409。这是故意的，别改成并行。
9. **改完前端要重新打包 APK**，`npm run android:apk`（约 1 分钟）。只改后端不用重打包。
