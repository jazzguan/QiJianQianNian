# zjz 形态对比

更新：2026-10-15。完整状态见[分支完成情况](branch-status.md)。

## 操作

1. 在左右下拉框选择馆藏、本人重建模型或已导入模型。
2. 登录后可导入自包含 GLB，支持 Y / Z / X 与反向竖直轴，文件上限20MB、30万面。
3. 可填写两侧实物高度，以厘米为单位。留空时使用馆藏明确记录的高度；未提供高度的模型保留归一化测量。
4. 点击“开始对比”，查看同步三维视图、部位对齐、参数表、轮廓叠加、厘米尺寸及馆藏特征。
5. CSV包含基础参数、内壁结果、厘米尺寸、标定来源、差异洞察与来源链接。AI按钮生成带资料引用的解释。

导入文件保存在当前账号的模型记录中，其他账号无法读取。运行 `./start.ps1` 后打开 `http://127.0.0.1:8000/comparison`。

## 测量

场景节点变换先应用到网格。导入时按所选竖直轴转到Y轴，XZ居中、底部归零、高度30。网格在0.5%至99.5%高度取101个水平截面；截面凸包通过旋转卡尺计算最大外径。口、足外径取顶、底邻近3%高度的中位外径。腹径位置为最大截面距底部的高度占比。

照片模型使用馆藏照片轮廓；官方扫描、导入和重建模型使用实际三角网格。两种来源在页面分别标注。

内壁测量要求截面同时包含闭合的外轮廓和内轮廓，计算内径与内轮廓到外轮廓的距离。没有内壁时结果为空。壁厚取器口邻近截面，不输出全器身壁厚分布。

厘米结果按 `归一化测量 × 实物高度 / 30` 换算。标定来源与数值随测量返回；比例表和厘米表分别展示。

## 接口

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| GET | `/api/comparison/artifacts` | 公开馆藏和当前账号已完成模型 |
| POST | `/api/measure` | `artifactId` 或 `modelUrl`，可附 `heightCm` |
| POST | `/api/measure/upload` | multipart `file`、`upAxis`、可选 `heightCm` |
| POST | `/api/compare` | `leftId/rightId`，可附双方模型URL及 `leftHeightCm/rightHeightCm` |
| POST | `/api/compare/explain` | 根据同一选择生成 AI 对比解释 |

对比返回原有六项 `rows`，附加 `cavityRows`、`physicalRows`、双方器物、测量、标定及来源。历史上传任务仍支持 `/files/{id}/mesh.glb`。完整字段见服务 `/docs`。
