更新：2026-10-14。基于 master 提交 `c104cdc01b929f733ec046b5626d49736e603dc4`。

## 形态对比功能

| 项目 | 已完成 | 未完成或数据缺口 |
| --- | --- | --- |
| 模型选择与导入 | 左右选择目录器物、当前重建模型、直接导入 GLB；导入文件和目录信息在本机持久保存 | 内置真实馆藏与官方扫描模型数据集；目前内置 5 件仓库示例轮廓 |
| 坐标与测量 | Y / Z / X 及反向竖直轴选择；应用场景变换；底部归零、高度统一为 30；101 个截面；六项自动测量 | 厘米尺度校准、内口径和胎壁厚度测量 |
| 双模型交互 | 同步旋转缩放、独立模式、视角重置；器口、器颈、肩部、腹部、器足定位高亮与双侧聚焦 | 自动部位语义分割；当前使用目录标注或预设高度区间 |
| 对照与导出 | 参数表、截面轮廓叠加、规则差异说明、CSV 导出；器型、纹饰、工艺、材质、用途、历史背景对照 | 5 件内置示例缺少材质与用途字段；导入 GLB 没有附带历史资料；自动纹饰识别与工艺原因分析 |
| 服务与异常处理 | 独立 FastAPI 服务；启动脚本；加载、计算和导入失败提示与重试；切换后清除旧结果；模型加载失败显示错误 | 云端 LLM / RAG 对比讲解，当前差异文案根据测量规则生成 |

六项参数为高度、最大腹径、口径、足径、高腹径比、最大腹径的相对高度。口径和足径为外径；所有几何尺寸使用归一化单位（高度=30）。缺失资料在页面显示“未提供资料”。

## 仓库其他功能

| 模块 | 此分支状态 |
| --- | --- |
| 前端 + 三维重建 | 保留 master 的 React 界面和 TripoSR 真实重建服务；重建结果仍使用固定示例器物元数据。独立形态服务无需加载重建模型权重 |
| 历史演化 | 保留 5 件示例及 Mock 接口；上传识别与历史匹配仍为固定示例逻辑，真实数据和匹配后端未完成 |
| AI 讲解 | 保留预设问答；云端文本生成、知识库、RAG 后端未完成 |
| 账号、学习中心、个人记录 | 未接入 zjz 分支的账号系统、学习任务和个人数据库 |

本分支新增代码集中在形态对比、测量接口与公共查看器。`zjz` 的真实馆藏、云端识别与讲解、账号和学习中心尚未合并过来；本分支的 GLB 导入、竖直轴选择、轮廓叠加、CSV 导出也尚未合并到 `zjz`。详见[zjz 分支状态](https://github.com/jazzguan/QiJianQianNian/blob/zjz/docs/branch-status.md)。
