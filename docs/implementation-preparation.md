克利夫兰 API 中，按馆藏文化描述匹配唐、宋、元、明、清，并筛选瓶、罐、碗、杯、盘、执壶等器物，分别得到 22、86、43、83、233 条候选记录。部分记录跨两个时期，不能把这些分组相加作为独立器物总数。

首期已导入20件器物，唐、宋、元、明、清各4件，保留原始年代与馆藏编号；演化比较按同器型组织。

## 数据分别解决的问题

- 器物与知识数据：名称、馆藏编号、年代、器型、材质、工艺、用途、尺寸、图片、说明、来源与许可，用于浏览、筛选、匹配、讲解和学习任务。
- 识别评测数据：从馆藏候选中另选带明确类别和年代记录的图片，检查云端视觉模型识别结果；与用于提示示例的图片分开。
- 三维参考数据：来自实际开放模型文件，用于历史三维展示和几何比较；馆藏厘米尺寸与程序归一化尺寸分别保存。

采用云端视觉模型时，首版可直接完成图像识别接入；不需要先训练一个新的瓷器分类模型。是否训练专用模型由后续识别评测结果决定。

## 可独立实施的功能

- 文物库、搜索、类别与年代筛选、详情和来源展示。
- 学习中心、观察与判断任务、年代排序、答题反馈和学习记录。
- 模型保存、历史任务恢复与下载。
- 时间轴拖动、三维平移与聚焦、真实 GLB 的部位点击和高亮。
- 重建实际阶段反馈、模型优化与接口统一。

云端 API 已接入器物识别和带来源的问答生成；器型匹配使用实际识别结果与器物库检索。实现记录见[implementation.md](implementation.md)。
